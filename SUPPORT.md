# Support

The Community project is currently unreleased. During this period, only the
current development branch is available for evaluation; no stable support
window or compatibility guarantee has been announced.

After the first stable release:

- Open a **Bug report** issue for reproducible defects.
- Open a **Question** issue for usage help, including the .NET SDK version,
  operating system, relevant package versions, and a minimal example.
- Use the **Feature request** form to describe the problem a proposed change
  would solve.
- Report security issues privately using the instructions in `SECURITY.md`.

Please search existing issues before opening a new one. Do not post credentials,
private customer data, or proprietary source in an issue. Support is best effort
and is limited to the Community components described in the README.
