Remarks

This checkpointer serialises each WorkflowSnapshot as UTF-8 JSON and stores it under the key myagents:checkpoint:{sessionId}. Key naming can be customised via the keyPrefix constructor parameter.

To use with Redis: 

// 1. Reference  Microsoft.Extensions.Caching.StackExchangeRedis
services.AddStackExchangeRedisCache(o => o.Configuration = "localhost:6379");

// 2. Register the checkpointer (IDistributedCache is resolved from DI)
services.AddSingleton<IWorkflowCheckpointer, DistributedCacheCheckpointer>();

To scope checkpoints to a particular expiry window use the cacheOptions overload: 

var options = new DistributedCacheEntryOptions
{
    AbsoluteExpirationRelativeToNow = TimeSpan.FromDays(7)
};
new DistributedCacheCheckpointer(cache, options);

Parameters

cache IDistributedCache

The distributed cache backend (Redis, SQL Server, etc.). Must be registered in DI or passed directly.

cacheOptions DistributedCacheEntryOptions

Optional sliding / absolute expiry settings. When null entries persist until explicitly removed or the cache evicts them.

keyPrefix string

Prefix added to every cache key, e.g. "myagents:checkpoint:" (default). Change this to isolate checkpoints from other cache entries.
