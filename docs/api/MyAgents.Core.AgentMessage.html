public AgentMessage(string Role, string Content, string? CorrelationId = null, string? ThreadId = null, string? SenderId = null, IReadOnlyList<AgentContent>? ContentParts = null)

Parameters

Role string

The role of the message sender (e.g., "user", "assistant", "system", "tool").

Content string

The primary text content of the message. For text-only messages this is the full payload. When ContentParts is set this field holds a text summary or is empty.

CorrelationId string

Optional correlation ID for tracing a message across agent boundaries.

ThreadId string

Optional thread/conversation ID grouping related turns together.

SenderId string

Optional identifier for the agent or user that originated this message.

ContentParts IReadOnlyList<AgentContent>

Optional multi-modal content parts. When present, the adapter layer maps each AgentContent part to the backend's native content type. If null, the message is treated as plain text via Content.
