Registers the core MyAgents services required to create and run agent sessions.

services IServiceCollection

IServiceCollection

The same services for chaining.

Remarks

This registers IAgentSessionFactory as a singleton backed by DefaultAgentSessionFactory. The factory depends on an IAgentRuntime that must be registered separately (either directly or via a runtime-specific extension such as AddMafRuntime()).

Registration uses TryAddSingleton<TService, TImplementation>(IServiceCollection) so calling this method multiple times is safe — the second call is a no-op. 

services.AddMyAgents();
// …then register your runtime:
services.AddSingleton<IAgentRuntime, MyRuntime>();
