Namespace MyAgents.Agents

Classes

AgentChannelFeature

Feature that wires an IAgentChannel into the agent's session DI overlay, making it available to tools and middleware via context.Services.GetService<IAgentChannel>().

AuditOnlyViolationHandler

Never blocks: records every finding to telemetry and lets the turn proceed. Intended for a shadow-mode rollout, so trigger rates can be measured on real traffic before enforcement.

BlocklistGuardrailPolicy

Flags turns whose output contains any of the configured blocked phrases (case-insensitive).

CanaryDefenseFeature

Opt-in egress defense: issues a per-session canary, instructs the model to treat it as a secret, and refuses any turn or tool call that would carry it (or a configured heuristic signal) out of the process.

CanaryDefenseOptions

Tuning for CanaryDefenseFeature. Detection and observability — how a violation is reacted to is decided by ICanaryViolationHandler.

CapabilityFeature

Feature that declares one or more IAgentCapability entries for an agent. Capabilities are stored on Capabilities so that orchestrators, routers, and tooling can discover what the agent supports at runtime without inspecting the full feature list.

CapabilityRouter

Single-hop LLM-based router. Given a task description and a set of candidate AgentDefinitions, calls the LLM once to select the best agent.

CapabilityRouterResult

The result of a single-hop routing decision.

ContextWindowFeature

Feature that adds ContextWindowMiddleware to the agent pipeline. Trims the incoming message history on every turn so the inner pipeline never sees more messages than the configured window allows.

DelegateToSubagentTool

Tool that enables an agent to synchronously delegate a specialized task to a subagent and receive its distilled execution result.

EmptyResponseGuardrailPolicy

Flags turns whose combined output is empty or contains nothing but whitespace. This policy is always included in the default GuardrailsFeature configuration.

FallbackFeature

Feature that wires a FallbackMiddleware into the agent pipeline.

ForkSubagentTool

Tool that enables an agent to fork a subagent task asynchronously in the background.

FunctionCallingFeature

Enables framework-level function calling for runtimes that return tool-call envelopes as assistant messages instead of invoking tools natively.

GetSubagentTaskStatusTool

Tool that allows an agent to check the status or retrieve the result of an asynchronously forked subagent task.

GroupChat

A group chat where all registered agents receive each message and take turns responding. This is the simplest multi-agent pattern — round-robin or random selection among agents.

GroupChatOptions

Configuration for GroupChat.

GroupChatResult

Result of a GroupChat run.

GuardrailMiddleware

Middleware that applies a ordered sequence of IGuardrailPolicy checks to each agent turn's output. On the first violation the output is replaced with the policy's ReplacementMessage (or a generic fallback if none is supplied) and no further policies are evaluated.

GuardrailsFeature

Feature that adds content-safety guardrails to the agent pipeline.

HierarchicalSubagentDispatcher

Hierarchical subagent dispatcher that manages child agent sessions, isolated context execution, delegation depth recursion guards, and background task forking.

InMemoryTokenCostTelemetrySink

In-memory accumulator of model routing cost telemetry records.

LoggingFeature

Feature that adds logging middleware to the agent pipeline.

LoggingMiddleware

Middleware that logs agent turn execution.

MaxDelegationDepthExceededException

Exception thrown when a recursive subagent delegation exceeds the maximum allowable depth.

MaxLengthGuardrailPolicy

Flags turns whose combined output text exceeds maxLength characters.

MemoryFeature

Feature that wires an IMemoryStore into the agent session. After contributing, the store is available to middleware and tools via context.Services.GetService<IMemoryStore>().

ModelCandidate

A registered model candidate available for adaptive multi-model routing.

ModelFeature

Declares a preferred model for the current agent.

ModelPricing

Pricing specifications for a model candidate (USD per 1,000,000 tokens).

ModelRoutingCostMetrics

Structured telemetry recording for model selection, token consumption, and estimated cost.

MultiModelRoutingBuilder

Builder for configuring multi-model routing candidates and policies.

MultiModelRoutingChatClient

Adaptive multi-model routing and token/cost optimizing chat client. Routes turns between Economy, Standard, and Advanced models based on prompt complexity, cascades to fallback models on failure, and tracks tokens and dollar spend against budgets.

MultiModelRoutingOptions

Configuration options for multi-model routing and token/cost optimization.

MultiModelRoutingServiceExtensions

Service collection extensions for registering multi-model routing and token/cost optimization.

MyAgentsActivitySource

Framework-level OpenTelemetry activity source. Emits spans under the "MyAgents" source name, complementing MEAI's "Microsoft.Extensions.AI" source which covers the LLM call layer.

MyAgentsOtelExtensions

Extension methods for registering MyAgents telemetry with OpenTelemetry. Designed to work with both the standard OTel SDK and .NET Aspire's automatic OTLP export pipeline.

PromptRegistryFeature

Feature that wires a PromptRegistry into the agent session and optionally renders selected templates into the agent's system prompt at assembly time.

QuarantineSessionViolationHandler

Quarantines the session and aborts when a canary is confirmed; leaves Suspicious findings non-blocking so heuristics can be measured on real traffic before they are trusted. This is the default handler.

RoutingException

Thrown when CapabilityRouter cannot match the LLM response to any registered agent and no fallback policy is configured.

SelectorGroupChat

A group chat where an LLM selects which agent should speak next based on the conversation context. This is the AutoGen SelectorGroupChat pattern.

SelectorGroupChatOptions

Configuration for SelectorGroupChat.

SelectorGroupChatResult

Result of a SelectorGroupChat run.

StructuredOutputFeature<T>

Feature that enables strongly-typed structured output for an agent, configuring the agent's schema and providing self-correction retries if the response is invalid JSON.

StructuredOutputMiddleware<T>

Middleware that sets the AgentResponseFormat on each turn and validates/retries if the model response does not conform to T.

SubagentDelegationFeature

Feature that equips an agent with subagent delegation tools (delegate_to_subagent, fork_subagent, get_subagent_task_status).

SubagentOrchestratorBuilder

Builder for configuring hierarchical subagent registrations.

SubagentOrchestratorOptions

Configuration options for hierarchical subagent orchestration and handoff execution.

SubagentResult

The final execution outcome and distilled output of a subagent turn or multi-turn execution.

SubagentServiceExtensions

Service collection extensions for hierarchical subagent orchestration.

SubagentTask

Task definition dispatched to a specialized subagent.

SubagentTaskHandle

Handle representing an asynchronously forked subagent task running in the background.

TelemetryFeature

Feature that adds TelemetryMiddleware to the agent pipeline. Compose alongside LoggingFeature — order determines span nesting. Typically added after LoggingFeature so the OTel span is the outermost wrapper.

TelemetryMiddleware

Middleware that wraps each agent turn in an OpenTelemetry Activity span. Tags emitted (MyAgents convention): agent.session_id — from AgentTurnContext.SessionId agent.turn.tool_calls — from AgentTurnResult.Telemetry.ToolCalls agent.turn.duration_ms — from AgentTurnResult.Telemetry.TurnDuration Tags emitted (GenAI convention): gen_ai.operation.name — "chat.completion" gen_ai.request.model — from AgentTurnResult.Telemetry.ModelId gen_ai.response.model — from AgentTurnResult.Telemetry.ModelId gen_ai.usage.input_tokens — from AgentTurnResult.Telemetry.PromptTokens gen_ai.usage.output_tokens — from AgentTurnResult.Telemetry.CompletionTokens gen_ai.usage.total_tokens — PromptTokens + CompletionTokens On exception, the span status is set to Error with the exception message.

TokenBudgetQuotaException

Exception thrown when a turn or session token volume or dollar cost quota is breached.

ToolObserverFeature

Feature that registers one or more IToolCallObserver instances into the agent assembly so the adapter fires them around every tool invocation.

ToolsFeature

Feature that registers one or more ITool instances or delegates on an agent definition.
