Quarantines the session and aborts when a canary is confirmed; leaves Suspicious findings non-blocking so heuristics can be measured on real traffic before they are trusted. This is the default handler.

Remarks

A confirmed canary has no legitimate reason to appear in output or in a tool argument, so the conversation is already compromised by the time it is seen. Quarantine is monotonic: every subsequent turn in that session is refused, which denies an attacker the turn-by-turn probing that an open session would allow.

Suspicious findings deliberately do not abort. Markdown beacons and high-entropy URLs have false positives; blocking on them by default would break legitimate turns before an operator has had a chance to see what the rate looks like.
