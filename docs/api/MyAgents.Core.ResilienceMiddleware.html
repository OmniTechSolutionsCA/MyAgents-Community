Remarks

An exception implementing INonRetryableException is never retried, even when the configured ITransientErrorClassifier reports it as transient. A classifier infers transience from the exception's type, which an application can widen indiscriminately; a marker on the exception itself is the throwing site's own statement that the failure is terminal.

InvokeStreamingAsync(AgentTurnContext, Func<AgentTurnContext, CancellationToken, IAsyncEnumerable<AgentTurnResult>>, CancellationToken)

Streaming variant: if the stream faults with a transient error before any chunk has been yielded to the caller, the stream is restarted from scratch (up to MyAgents.Core.ResilienceMiddleware._maxRetries times with exponential back-off). Once at least one chunk has been forwarded a retry is suppressed — restarting mid-stream would produce duplicate or confusing output for the caller.

The enumerator is driven manually (rather than with await foreach) so that MoveNextAsync can be called inside a try/catch block, while yield return sits outside any catch clause — a requirement imposed by the C# compiler for async iterator methods.
