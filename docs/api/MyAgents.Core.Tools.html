Namespace MyAgents.Core.Tools

Classes

AgentFunctionCall

Canonical framework-level representation of a model-emitted function call.

The normalized JSON envelope emitted by AgentFunctionCallSerializer is:

{
  "type": "function_call",
  "id": "call-1",
  "name": "tool_name",
  "arguments": { ... }
}
AgentFunctionCallSerializer

Serializes and parses canonical function-call envelopes. Parsers accept both the canonical schema and the legacy aliases already supported by the framework middleware.

AgentToolAttribute

Marks a method as an agent tool to be generated at compile time by the Roslyn source generator. The generated tool embeds its JSON schema as a compile-time constant and binds primitive arguments (string, bool, int, long, float, double, decimal) without reflection or boxing. Other parameter and return types use reflection-based System.Text.Json serialization unless JsonContext supplies source-generated serialization metadata.

DefaultProcessRunner

Default IProcessRunner implementation that uses Process.

DelegateTool

An ITool implementation backed by a C# Delegate (such as a method, lambda, or local function) with automatic JSON schema generation, compiled invocation, and zero-reflection argument deserialization.

HandoffTool

A tool that allows an agent to explicitly hand off the conversation to another agent. The orchestrator (e.g., RunHandoffAsync<TState>(IWorkflowSession<TState>, string, IReadOnlyList<AgentMessage>, Func<AgentTurnResult, int, string?>, ITerminationCondition?, int, CancellationToken)) can detect this tool call and perform the switch.

ProcessResult

Result returned by IProcessRunner after a process exits.

ToolCallObservation

Describes a tool call that was about to be (or was) invoked by the agent.

ToolResultObservation

Describes the result of a completed tool call.

Interfaces

IProcessRunner

Abstraction for running a child process and capturing its output.

ITool

A tool that can be invoked by an agent.

IToolCallObserver

Intercepts tool call/result pairs at the framework layer. Observers are called for every function call the model emits, regardless of which tool it targets.

Add observers to ToolObservers from an Contribute(AgentAssembly) implementation, or directly on the assembly before session creation.
