Middleware that trims the incoming message history before forwarding the turn to the inner pipeline. This prevents context-window overflow on long-running conversations without modifying call-site code.

Remarks

Compose this middleware early in the pipeline (before telemetry and resilience middleware) so that every downstream layer sees the already-trimmed history.

The trimmer is invoked on every turn. For conversations well within the window the trimmer returns immediately with the original list, incurring no allocations. 

var agent = new AgentDefinition(
    Name: "MyAgent",
    Features: new IAgentFeature[]
    {
        new ContextWindowFeature(maxMessages: 20),
        new TelemetryFeature(),
    });

Remarks

A middleware that relies on this default narrows the stream to a single chunk: the chunks are accumulated into the shape a blocking turn would have produced (see AgentOutputAccumulator), the blocking InvokeAsync(AgentTurnContext, Func<AgentTurnContext, CancellationToken, ValueTask<AgentTurnResult>>, CancellationToken) path runs once against that result, and the outcome is yielded at the end of the turn. Callers receive the full accumulated content, but not incrementally — token-by-token delivery requires overriding this method.
