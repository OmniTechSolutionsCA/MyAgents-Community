Opt-in egress defense: issues a per-session canary, instructs the model to treat it as a secret, and refuses any turn or tool call that would carry it (or a configured heuristic signal) out of the process.

Remarks

This raises the cost of exfiltration; it does not close the channel. An attacker who knows the scheme can still leak information through signals that never touch a scanned payload. Configure it alongside least-privilege tools and human approval, not instead of them.

Streaming becomes buffered for any agent using this feature, because a canary can appear in the final tokens of a reply and text already handed to a caller cannot be retracted. 

var agent = new AgentDefinition(
    Name: "GuardedAgent",
    Features: new IAgentFeature[]
    {
        new ToolsFeature(...),
        new CanaryDefenseFeature(),
    });
