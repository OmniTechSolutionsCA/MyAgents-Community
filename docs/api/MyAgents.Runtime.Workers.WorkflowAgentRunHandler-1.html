Remarks

This adapter persists workflow snapshots when the workflow pauses for human input or tool approval. For checkpoints between those pauses, workflow handlers should call SaveCheckpointAsync(string, CancellationToken) with a handler-defined resumable payload.

Serialization metadata is supplied explicitly for trimming and NativeAOT-friendly use.
