The purpose of this method is to allow for the retrieval of strongly typed services that might be provided by the Microsoft.Extensions.AI.IEmbeddingGenerator<TInput, TEmbedding>, including itself or any services it might be wrapping. For example, to access the Microsoft.Extensions.AI.EmbeddingGeneratorMetadata for the instance, GetService(Type, object) may be used to request it.
