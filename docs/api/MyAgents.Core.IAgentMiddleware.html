InvokeStreamingAsync(AgentTurnContext, Func<AgentTurnContext, CancellationToken, IAsyncEnumerable<AgentTurnResult>>, CancellationToken)

Invokes the middleware for a streaming turn. The default implementation delegates to InvokeAsync(AgentTurnContext, Func<AgentTurnContext, CancellationToken, ValueTask<AgentTurnResult>>, CancellationToken) and yields the result as a single chunk, so existing middleware participates in streaming without any changes. Override to implement true streaming interception.

Remarks

A middleware that relies on this default narrows the stream to a single chunk: the chunks are accumulated into the shape a blocking turn would have produced (see AgentOutputAccumulator), the blocking InvokeAsync(AgentTurnContext, Func<AgentTurnContext, CancellationToken, ValueTask<AgentTurnResult>>, CancellationToken) path runs once against that result, and the outcome is yielded at the end of the turn. Callers receive the full accumulated content, but not incrementally — token-by-token delivery requires overriding this method.
