Class InMemoryMemoryStore

Namespace
MyAgents.Core.Memory
Assembly
MyAgents.Core.dll

Thread-safe, in-process implementation of IMemoryStore. Entries are partitioned by namespace in a ConcurrentDictionary<TKey, TValue> for O(1) lookups and isolated namespace searches. Suitable for single-process agents and tests. For multi-process or persistent memory, replace with a vector-store or Redis-backed implementation behind the same interface.
