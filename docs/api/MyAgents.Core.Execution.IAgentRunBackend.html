MyAgents.Core.Execution

Durable lifecycle and queue boundary for agent runs. Implementations must make submission, claim, lease, and terminal transitions atomic within their own persistence boundary.

public interface IAgentRunBackend

Remarks

Delivery is at-least-once. Implementations should use fencing tokens to reject updates from workers whose lease has expired or been replaced. This contract does not provide exactly-once external side effects.
