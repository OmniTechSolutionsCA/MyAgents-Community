Class InMemoryGraphHistoryStore

Namespace
MyAgents.Core.Workflows

In-process, in-memory implementation of IGraphHistoryStore. Snapshots are stored for the lifetime of the object and lost when it is garbage-collected. Suitable for testing and single-process deployments; for distributed or durable scenarios replace with a database-backed implementation.
