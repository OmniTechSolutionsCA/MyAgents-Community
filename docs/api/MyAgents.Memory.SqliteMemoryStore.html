Class SqliteMemoryStore

Namespace
MyAgents.Memory
Assembly
MyAgents.Memory.dll

Durable SQLite-backed implementation of IVectorMemoryStore and IMemoryStoreChangeNotifier. Persists MemoryEntry records, JSON metadata, and pre-normalized float embeddings in a single SQLite database while maintaining an in-memory cache for microsecond-latency SIMD Dot(ReadOnlySpan<float>, ReadOnlySpan<float>) vector search. Also skips redundant embedding generation when upserting an entry whose content is unchanged.
