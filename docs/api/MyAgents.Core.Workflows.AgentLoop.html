A standalone ReAct-style agent loop that drives a single agent session until a termination condition is met or maxTurns is exhausted.

This is the building block for single-agent reasoning loops that don't require the full WorkflowHost / IWorkflow<TState> machinery. For multi-agent orchestration use WorkflowHost instead.

Examples

var result = await AgentLoop.RunAsync(
    session,
    initialMessages: new[] { new AgentMessage("user", "Research AI agent frameworks.") },
    termination: ITerminationCondition.Any(
        new MaxTurnsTermination(maxTurns: 10),
        new TextMentionTermination("DONE")),
    maxTurns: 10);

Console.WriteLine(result.FinalResult.Output[0].Content);

RunAsync(IAgentSession, IReadOnlyList<AgentMessage>, ITerminationCondition, int, Action<AgentTurnResult, int>?, CancellationToken)

Runs the agent in a loop until the termination condition is met or maxTurns is exceeded, whichever comes first.

public static ValueTask<AgentLoopResult> RunAsync(IAgentSession session, IReadOnlyList<AgentMessage> initialMessages, ITerminationCondition termination, int maxTurns = 20, Action<AgentTurnResult, int>? onTurnCompleted = null, CancellationToken cancellationToken = default)

Parameters

session IAgentSession

The agent session to invoke on each turn.

initialMessages IReadOnlyList<AgentMessage>

The messages to send on the first turn.

termination ITerminationCondition

Condition checked after each turn. When it returns true the loop stops. Use Any(params ITerminationCondition[]) / All(params ITerminationCondition[]) to combine conditions.

maxTurns int

Hard upper bound on turns. Defaults to 20.

onTurnCompleted Action<AgentTurnResult, int>

Optional callback invoked after each turn, before termination is evaluated. Useful for logging or streaming partial results to the caller.

cancellationToken CancellationToken

Cancellation token.

Returns

ValueTask<AgentLoopResult>

An AgentLoopResult containing all turn results, the final result, the termination reason, and the number of turns completed.

RunAsync<TState>(IAgentSession, TState, IReadOnlyList<AgentMessage>, Func<TState, AgentTurnResult, TState>, ITerminationCondition, int, Action<TState, AgentTurnResult, int>?, CancellationToken)

Runs the agent in a loop with typed state that is updated by a reducer after every turn. Useful for ReAct-style loops where the agent accumulates structured results (e.g. a research summary, a tool output list) across turns.

public static ValueTask<AgentLoopResult<TState>> RunAsync<TState>(IAgentSession session, TState initialState, IReadOnlyList<AgentMessage> initialMessages, Func<TState, AgentTurnResult, TState> reducer, ITerminationCondition termination, int maxTurns = 20, Action<TState, AgentTurnResult, int>? onTurnCompleted = null, CancellationToken cancellationToken = default)

Parameters

session IAgentSession

The agent session to invoke on each turn.

initialState TState

The initial value of TState.

initialMessages IReadOnlyList<AgentMessage>

The messages to send on the first turn.

reducer Func<TState, AgentTurnResult, TState>

A pure function that merges the current state with the turn result to produce the next state. Called after every turn, before termination is evaluated.

termination ITerminationCondition

Condition checked after each turn.

maxTurns int

Hard upper bound on turns. Defaults to 20.

onTurnCompleted Action<TState, AgentTurnResult, int>

Optional callback invoked after the reducer runs, before termination is checked. Receives the updated state, the raw turn result, and the current turn number.

cancellationToken CancellationToken

Cancellation token.

Returns

ValueTask<AgentLoopResult<TState>>

An AgentLoopResult<TState> containing all turn results, the final result, the final state, the termination reason, and the number of turns completed.

Type Parameters

TState

Caller-defined state type. Must be JSON-serializable (System.Text.Json) so that it can be checkpointed. Recommend using an immutable record.
