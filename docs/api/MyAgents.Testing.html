Namespace MyAgents.Testing

Classes

FakeAgentSession

A test-friendly IAgentSession that wraps an InMemoryAgent and exposes all invocation records for assertion.

InMemoryAgent

A deterministic, in-memory IAgent implementation for unit testing. Returns pre-programmed responses in order; after the queue is exhausted, returns a configurable fallback response (default: empty assistant message).

InMemoryAgentRunBackend

Single-process implementation of IAgentRunBackend for deterministic tests and local development. It does not survive process exit or coordinate separate processes.

InMemoryAgentRuntime

An in-memory IAgentRuntime for unit testing. Creates InMemoryAgent instances keyed by agent name. Each named agent has its own response queue; all created agents are tracked so tests can assert on invocation counts and received messages.
