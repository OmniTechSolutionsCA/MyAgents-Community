Remarks

Aspire usage (AppHost): The .NET Aspire AppHost automatically configures OTLP export — no exporter code is needed in your application. Just call the extension methods below in your application's Program.cs: 

// Program.cs (Aspire service project)
builder.Services.AddOpenTelemetry()
    .AddMyAgentsTracing()
    .AddMyAgentsMetrics();

Non-Aspire usage: Add your own exporter: 

builder.Services.AddOpenTelemetry()
    .AddMyAgentsTracing()
    .AddMyAgentsMetrics()
    .WithTracing(b => b.AddOtlpExporter())
    .WithMetrics(b => b.AddOtlpExporter());
