Zero-dependency IDocumentReader that extracts structured text and titles from HTML documents. Strips <script>, <style>, <svg>, and <noscript> blocks, converts HTML headings (<h1>–<h6>), paragraphs, list items, and line breaks into Markdown-compatible text, and decodes HTML entities.
