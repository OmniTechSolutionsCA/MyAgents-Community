Parameters

SnapshotId string

Unique snapshot identifier (e.g. "snap-{guid}").

SessionId string

The session this snapshot belongs to.

WorkflowId string

Identifies the graph type (e.g. "AgentGraph<MyState>").

NodeName string

Name of the node that produced this snapshot.

StateVersion int

Monotonically increasing version within the session. Starts at 1 and increments after each node execution (including parallel fan-out branches).

StateJson string

JSON-serialized graph state after this node completed.

CreatedAt DateTimeOffset

UTC timestamp when this snapshot was created.

ParentSnapshotId string

Snapshot ID of the immediately preceding snapshot in this session's execution chain. null for the first snapshot in a session or branch.

BranchedFromSessionId string

Session ID of the original session from which this branched session was created via ResumeFromSnapshotAsync(string, string, string?, CancellationToken). null when this is the root (un-branched) session.
