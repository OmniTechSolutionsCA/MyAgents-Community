Remarks

State transitions:

  • Closed → Open: failureThreshold consecutive transient failures (as classified by the ITransientErrorClassifier).
  • Open → HalfOpen: openDuration has elapsed.
  • HalfOpen → Closed: the probe call succeeds.
  • HalfOpen → Open: the probe call fails.

This middleware is thread-safe. Compose it at the outermost position in the pipeline, before ResilienceMiddleware, so retries are not attempted when the circuit is open.

Parameters

failureThreshold int

Number of consecutive transient failures that trips the circuit. Default: 5.

openDuration TimeSpan?

How long the circuit stays open before transitioning to HalfOpen for a probe. Default: 30 seconds.

classifier ITransientErrorClassifier

Determines which exceptions count as circuit-tripping failures. Defaults to DefaultTransientErrorClassifier.

logger ILogger<CircuitBreakerMiddleware>

Optional logger. Defaults to NullLogger.
