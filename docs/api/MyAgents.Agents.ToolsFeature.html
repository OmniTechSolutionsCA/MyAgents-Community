Contribute(AgentAssembly)

Synchronously contributes to the agent assembly (tools, middleware, prompts). Prefer overriding ContributeAsync(AgentAssembly, CancellationToken) when the feature needs to perform async I/O (e.g. connecting to a remote server). The default implementation of ContributeAsync(AgentAssembly, CancellationToken) delegates here, so features that have no async work only need to implement this method.
