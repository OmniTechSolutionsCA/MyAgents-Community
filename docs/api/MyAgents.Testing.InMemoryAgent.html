Class InMemoryAgent

Namespace
MyAgents.Testing
Assembly
MyAgents.Testing.dll

A deterministic, in-memory IAgent implementation for unit testing. Returns pre-programmed responses in order; after the queue is exhausted, returns a configurable fallback response (default: empty assistant message).

public sealed class InMemoryAgent : IAgent, IDisposable

Remarks

Usage:

var agent = new InMemoryAgent("TestAgent")
    .EnqueueResponse("Paris")
    .EnqueueResponse("France");

var result = await agent.InvokeAsync(context, ct);
Assert.Equal("Paris", result.Output[0].Content);
