Class VectorDataMemoryStore

Namespace
MyAgents.Memory
Assembly
MyAgents.Memory.dll

Adapter that implements IVectorMemoryStore and IMemoryStoreChangeNotifier over any Microsoft.Extensions.VectorData.VectorStore or Microsoft.Extensions.VectorData.VectorStoreCollection<TKey, TRecord> (such as Qdrant, pgvector, Azure AI Search, SQLite-vec, or Redis) without coupling MyAgents.Memory to any vendor SDK.
