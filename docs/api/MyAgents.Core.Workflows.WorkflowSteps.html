Namespace
MyAgents.Core.Workflows

Orchestration helpers for common workflow patterns. Workflows call these from within their RunAsync implementation.

Sequential: steps run one after another, each receiving the prior output Concurrent: steps run in parallel, results collected Handoff: one agent processes and decides which agent to hand off to next

RequestHumanInputAsync<TState>(IWorkflowSession<TState>, string, string, CancellationToken)

Pauses the workflow to request a human reply, serialising current state into a snapshot.

public static ValueTask RequestHumanInputAsync<TState>(IWorkflowSession<TState> session, string stepId, string prompt, CancellationToken cancellationToken = default)

Parameters

Returns

ValueTask

Type Parameters

Remarks

This method always throws HumanInputRequiredException. The workflow execution unwinds — no code after this call runs until the workflow is resumed via ResumeWithInputAsync<TState>(IWorkflow<TState>, WorkflowSnapshot, string, JsonSerializerOptions?, CancellationToken).

Exceptions

HumanInputRequiredException

Always thrown to unwind the workflow.

RunHandoffAsync<TState>(IWorkflowSession<TState>, string, IReadOnlyList<AgentMessage>, Func<AgentTurnResult, int, string?>, ITerminationCondition?, int, CancellationToken)

Handoff pattern: calls an initial agent, then uses a selector function to decide which agent to hand off to next, repeating until the selector returns null.

public static ValueTask<AgentTurnResult> RunHandoffAsync<TState>(IWorkflowSession<TState> session, string firstAgentName, IReadOnlyList<AgentMessage> initialMessages, Func<AgentTurnResult, int, string?> nextAgentSelector, ITerminationCondition? termination = null, int maxHops = 10, CancellationToken cancellationToken = default)

Parameters

session IWorkflowSession<TState>

The workflow session.

firstAgentName string

The first agent to invoke.

initialMessages IReadOnlyList<AgentMessage>

Initial input messages.

nextAgentSelector Func<AgentTurnResult, int, string>

Returns the name of the next agent to invoke, or null to stop. Receives the current result and the number of hops completed so far.

termination ITerminationCondition

Optional termination condition checked after every turn. If it returns true, the loop stops immediately. Works alongside maxHops — whichever triggers first wins.

maxHops int

Safety cap on total handoffs (default: 10).

cancellationToken CancellationToken

Cancellation token.

Returns

ValueTask<AgentTurnResult>

The final agent's result.

RunStreamingBridgeAsync<TState>(IWorkflowSession<TState>, string, IReadOnlyList<string>, IReadOnlyList<AgentMessage>, Action<AgentTurnResult>?, Func<IReadOnlyList<AgentMessage>, AgentMessage>?, CancellationToken)

Streaming bridge pattern. Streams the source agent live (yielding each chunk to the onChunk observer), compacts the buffered output into a single message, then runs the downstream agents sequentially using the compacted content as input.

public static ValueTask<AgentTurnResult> RunStreamingBridgeAsync<TState>(IWorkflowSession<TState> session, string sourceAgentName, IReadOnlyList<string> downstreamAgentNames, IReadOnlyList<AgentMessage> initialMessages, Action<AgentTurnResult>? onChunk = null, Func<IReadOnlyList<AgentMessage>, AgentMessage>? compact = null, CancellationToken cancellationToken = default)

Parameters

session IWorkflowSession<TState>

The workflow session.

sourceAgentName string

Agent to invoke with streaming.

downstreamAgentNames IReadOnlyList<string>

Agents to invoke sequentially after streaming completes.

initialMessages IReadOnlyList<AgentMessage>

Messages for the source agent.

onChunk Action<AgentTurnResult>

Called with each streamed chunk for real-time UI delivery. May be null.

compact Func<IReadOnlyList<AgentMessage>, AgentMessage>

Optional function to compact the buffered stream into a single context message. Defaults to joining all chunk text with newlines.

cancellationToken CancellationToken

Cancellation token.

Returns

ValueTask<AgentTurnResult>

The final downstream agent result.

Type Parameters

TState

Remarks

Use this instead of RunSequentialAsync when you need the first agent's output to appear in real-time on a UI while the pipeline continues to completion.
