Searches for entries in the given namespace that are semantically similar to query using vector similarity.

ValueTask<IReadOnlyList<VectorSearchResult>> VectorSearchAsync(string ns, string query, int maxResults = 5, float minScore = 0, IReadOnlyDictionary<string, string>? metadataFilters = null, CancellationToken cancellationToken = default)

Parameters

ns string

Logical namespace (e.g., "facts", "conversation").

query string

Natural-language query to embed and search against.

maxResults int

Maximum number of results to return.

minScore float

Minimum similarity score threshold (0.0–1.0). Results below this are excluded. Defaults to 0.0 (return all results up to maxResults).

metadataFilters IReadOnlyDictionary<string, string>

Optional case-insensitive metadata filters evaluated before top-K selection.

cancellationToken CancellationToken

Cancellation token.

Returns

ValueTask<IReadOnlyList<VectorSearchResult>>

Matching entries ordered by descending similarity score, each paired with its score.
