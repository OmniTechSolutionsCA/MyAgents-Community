DocumentAgentContent

Document content part for files such as PDF and Office documents.

FallbackMiddleware

Middleware that catches exceptions escaping the inner pipeline and delegates recovery to an IFallbackPolicy. Place this at (or near) the outermost edge of the pipeline.

FunctionCallingMiddleware

Runtime-agnostic tool execution middleware.

When the inner agent returns an assistant message containing a supported function-call envelope, the middleware resolves the requested tool from the session ToolCatalog, invokes it, appends a tool message to the conversation, and reinvokes the inner pipeline until the agent returns a normal assistant response.

Trims the message history by removing the oldest non-system messages until the list contains at most maxMessages entries. System messages (role == "system") are always retained at their original position.

Trimmer that ensures the total token count for a conversation stays within a specified budget. System messages are never removed and always count toward the budget; non‑system messages are dropped oldest‑first until the remaining history fits.

Interfaces

IAgent

The core agent contract. All agents implement this interface.

IAgentCapability

Declares a named capability that an agent supports. Capabilities are informational — they allow orchestrators, routers, and tooling to discover what an agent can do without inspecting its feature list directly.

IAgentFeature

A feature that contributes capabilities to an agent. Features are composed, not inherited.

IAgentMiddleware

Middleware that intercepts agent turn execution.

IAgentRuntime

Runtime responsible for creating agents from definitions.

IAgentSession

Represents an active agent session with conversation state.

IAgentSessionFactory

Factory for creating agent sessions from definitions.

IContextWindowTrimmer

Decides how an AgentMessage sequence should be trimmed when the message history exceeds the configured window.

IDeadLetterQueue

Abstraction for a dead-letter sink that stores failed agent turns for later inspection, replay, or alerting.

IFallbackPolicy

Abstraction for handling exceptions that escape the agent pipeline. Implementations decide whether to return a fallback result, enqueue a dead-letter, rethrow, or take any other recovery action.

IGuardrailPolicy

A single, composable content-safety rule applied to the agent's output after each turn. Multiple policies are evaluated in registration order.

IRunTraceCatalog

Optional query surface for enumerating known run IDs from a trace sink.

IRunTraceSink

Persists normalized execution events for later inspection.

ISessionApprovalMemory

Maintains active session-scoped tool approval grants (e.g. "Always allow this tool for this session").

ITerminationCondition

Determines whether an agent loop or workflow handoff chain should terminate.

ITokenCounter

Counts tokens in a text string. Implementations may target a specific tokenizer or use a heuristic approximation.

IToolApprovalAuditSink

Sink for recording and auditing tool approval decisions across the platform.

IToolApprovalGate

Interactively or asynchronously resolves pending tool approvals (e.g., human-in-the-loop CLI prompts, webhooks, or external signals).

IToolApprovalInbox

Optional query surface for enumerating approval records across sessions.

IToolApprovalPolicy

Evaluates whether a tool invocation may proceed immediately or needs approval.

IToolApprovalStore

Stores pending and resolved tool approvals for workflows, sessions, and local studio inspection.

ITransientErrorClassifier
