Interface IGraphHistoryStore

Namespace
MyAgents.Core.Workflows
Assembly
MyAgents.Core.dll

Stores a versioned history of GraphSnapshot records, enabling time-travel and branch-replay operations on AgentGraph<TState> runs.

public interface IGraphHistoryStore

Remarks

Unlike IWorkflowCheckpointer — which stores only the latest checkpoint per session — IGraphHistoryStore retains every node snapshot, allowing callers to enumerate the full execution history and branch from any past state.
