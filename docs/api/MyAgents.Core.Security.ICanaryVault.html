Holds the canary tokens issued for one session and whether that session has been quarantined.

public interface ICanaryVault

Remarks

A canary is a high-entropy token that has no legitimate reason to appear in agent output or in a tool argument. Because it is meaningless outside the framework, a match is a confirmed exfiltration attempt rather than a heuristic.

Quarantine is monotonic: once a session is quarantined, nothing can clear it. A turn that caused a quarantine has already had its conversation poisoned, and leaving the session open would let an attacker probe the detectors turn by turn.
