Feature that adds ContextWindowMiddleware to the agent pipeline. Trims the incoming message history on every turn so the inner pipeline never sees more messages than the configured window allows.

Examples

var agent = new AgentDefinition(
    Name: "MyAgent",
    Features: new IAgentFeature[]
    {
        new ContextWindowFeature(maxMessages: 20),
        new TelemetryFeature(),
        new LoggingFeature(),
    });

Remarks

Compose this feature early in the features list — it should sit before TelemetryFeature and LoggingFeature so all downstream middleware work with the already-trimmed history.

public ContextWindowFeature(int maxMessages = 20)

Parameters

maxMessages int

Maximum number of non-system messages to retain per turn. Defaults to 20. System messages are always preserved. This overload uses a simple sliding window strategy; for token-based trimming use WithTokenBudget(int, ITokenCounter?) instead.
