AgentLoop

A standalone ReAct-style agent loop that drives a single agent session until a termination condition is met or maxTurns is exhausted.

This is the building block for single-agent reasoning loops that don't require the full WorkflowHost / IWorkflow<TState> machinery. For multi-agent orchestration use WorkflowHost instead.

HumanInputRequiredException

Thrown by RequestHumanInputAsync<TState>(IWorkflowSession<TState>, string, string, CancellationToken) to unwind the workflow execution stack and hand a serializable snapshot back to the caller.

The caller pattern is:

try
{
    var state = await host.RunAsync(workflow, initialState);
}
catch (HumanInputRequiredException ex)
{
    // Persist ex.Snapshot — it contains the paused state and the prompt to show the user.
    // Later, collect the human's reply and resume:
    var finalState = await host.ResumeWithInputAsync(workflow, ex.Snapshot, humanReply);
}
InMemoryGraphHistoryStore
