Interface IAgentChannel

Namespace
MyAgents.Core.Messaging
Assembly
MyAgents.Core.dll

An in-process pub/sub channel that lets agents communicate without being pre-wired to each other in a workflow topology.

  • Any agent can publish a message to the channel.
  • Any subscribed reader receives all messages (broadcast) unless filtered by TargetAgentName.
  • The channel is one-to-many: a single publish fans out to all active readers.
