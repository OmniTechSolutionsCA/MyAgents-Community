Interface IToolCallObserver

Namespace
MyAgents.Core.Tools
Assembly
MyAgents.Core.dll

Intercepts tool call/result pairs at the framework layer. Observers are called for every function call the model emits, regardless of which tool it targets.

Add observers to ToolObservers from an Contribute(AgentAssembly) implementation, or directly on the assembly before session creation. 

public interface IToolCallObserver

Remarks

Observers are called synchronously on the turn thread. Keep implementations fast; offload heavy work (DB writes, HTTP calls) to a background queue.
