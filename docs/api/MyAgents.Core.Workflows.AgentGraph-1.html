A directed graph that routes control flow between named agent nodes based on state transitions. Inspired by LangGraph's compile/run model but scoped to .NET idioms and the MyAgents IAgentSession contract.

Remarks

v2 capabilities: sequential execution, conditional routing, parallel fan-out via AddFanOutEdge(string, params string[]), streaming execution via RunStreamingAsync(string, TState, IReadOnlyList<AgentMessage>, string?, CancellationToken), time-travel / branch-replay via ResumeFromSnapshotAsync(string, string, string?, CancellationToken) (requires an IGraphHistoryStore), and max-iteration cycle guard.

Execution model: primary nodes execute sequentially. After a node completes, if a fan-out edge was registered via AddFanOutEdge(string, params string[]), the listed parallel nodes run concurrently and their states are merged in declaration order before routing continues. The merge delegate is called after every node (sequential or fan-out) to fold the node's returned state into the accumulated graph state.

merge Func<TState, TState, TState>

Called after every node to fold the node's output state into the accumulated graph state (first argument = current accumulated state, second = state returned by the node that just executed). Common implementations:

  • (_, b) => b — replace: the node's output becomes the new state.
  • (a, b) => a with { Field = b.Field } — selective merge: carry one field forward.

Hard upper bound on node transitions before the run is aborted with MaxIterationsReached. Defaults to 100.

Remarks

After fromNode completes and its state is merged, all parallelNodes execute concurrently via WhenAll(IEnumerable<Task>). Their states are merged in declaration order into the accumulated graph state. Once all branches finish, routing continues from fromNode's outgoing edge (set via AddEdge(string, string) or AddConditionalEdge(string, Func<TState, string>)).

Fan-out parallel nodes are leaf nodes in the fan-out subgraph — they supply results to the merge function but do not themselves determine the next sequential node.
