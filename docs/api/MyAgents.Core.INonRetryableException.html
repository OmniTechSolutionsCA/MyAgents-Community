Marks an exception as terminal: ResilienceMiddleware never retries it, regardless of what the configured ITransientErrorClassifier reports.

public interface INonRetryableException

Remarks

Use this for failures where a retry is not merely useless but actively wrong — a security violation, a policy rejection, or any abort whose cause cannot change by re-running the turn.

ITransientErrorClassifier answers what tends to be transient from an exception's type. That inference is deliberately coarse: an application may inject a classifier that reports every exception as transient, which would silently replay an abort that must be terminal. Implementing this interface lets the throwing site state what is known to be terminal, and it takes precedence over any classifier.

An exception implementing this interface is rethrown without the retry-exhausted metric being recorded, because no retry was attempted — it was never a retry-exhaustion.
