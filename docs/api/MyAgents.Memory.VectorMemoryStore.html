Class VectorMemoryStore

Namespace
MyAgents.Memory
Assembly
MyAgents.Memory.dll

Vector-backed implementation of IVectorMemoryStore that stores MemoryEntry records with their embeddings in memory, supports high-performance semantic search powered by SIMD-accelerated System.Numerics.Tensors.TensorPrimitives, and provides durable snapshot serialization to and from disk or streams.
