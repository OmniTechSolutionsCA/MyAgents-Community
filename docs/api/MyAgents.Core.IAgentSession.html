Remarks

Implement IAsyncDisposable to release resources asynchronously (e.g. open MCP server connections, streaming HTTP connections). The synchronous Dispose() is retained for backward compatibility and for use in using blocks that cannot await. Prefer await using over using for sessions created via CreateSessionAsync(string, AgentDefinition, CancellationToken) so that MCP and other async resources are torn down cleanly.
