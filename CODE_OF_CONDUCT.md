# Community Code of Conduct

We want MyAgents Community to be a respectful, useful place to learn and build.
Treat other participants with patience and respect, welcome differing
backgrounds and viewpoints, and keep feedback focused on ideas and behavior.

Unacceptable behavior includes harassment, discrimination, threats, deliberate
intimidation, unwanted sexual attention, personal attacks, and publishing
someone's private information without permission. This applies in repository
issues, pull requests, discussions, and other project spaces.

Project maintainers may edit or remove content and may warn, temporarily
restrict, or exclude participants who violate this code. Enforcement decisions
will be proportionate to the behavior and applied consistently.

## Reporting a concern

Please contact the maintainers privately using the contact method listed on
the [repository owner's GitHub profile](https://github.com/OmniTechSolutionsCA).
Do not post sensitive details in a public issue. Before the project accepts
outside contributions, maintainers must ensure that this private contact path
is available and monitored.
